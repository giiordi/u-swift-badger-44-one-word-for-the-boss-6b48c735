One word for the boss: **Jargonaut** — the boss who speaks only in corporate jargon, sailing every sentence through synergy, bandwidth, circling back and low-hanging fruit, and never once landing on a plain word. It is funny on its own, true of bosses in any kitchen, warehouse or office, and fresh enough that no colleague has heard it at lunch yet.

## Run it

```sh
node main.ts
```

The program validates the gate itself (exactly one word, letters only, 1–30 characters, no whitespace) and writes the word with no trailing newline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
